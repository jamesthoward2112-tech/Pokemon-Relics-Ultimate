PRU user-approved calf sprite redraws
====================================

Miltitan and Mootiny front artwork was supplied by James on 4 November 2026
in PRU_Miltitan_Mootiny_GBA_ready.zip. The checked-in PNG and JASC palettes
are the exact indexed source files from that archive.

The archive contains front views only. PRU keeps the approved existing back
views and maps their indexed colours to the new shared species palettes. The
archive supplies no shiny variants, so the shiny palettes currently duplicate
the approved normal palettes rather than inventing new shiny colours.

Party/PC icons are derived from each approved front drawing and remapped to
the existing shared icon palettes selected by SpeciesInfo. The build workflow
reinstalls these sources after upstream sprite synchronization.
