# PRU custom battle background first-pass pack (113 scenes)

112 planned locations plus a dedicated Ruins of Alph underground relic chamber. Built as distinct location-themed compositions/colour variants from six original PRU reference paintings, plus original procedural scenery and architecture. These are functional GBA test assets and are **not** 113 individually commissioned hand-painted scenes.

GBA format: 240x160, three 16-colour palette banks 12–14, <=512 4bpp tiles, original GBA LZ77 graphics compression. Opponent rings centered near (185,65), above the player's HP bar. All ROM integration is on a separate test branch; main Alpha 02 is unchanged.

Golden Ho-Oh uses scene 109, a dedicated gold-and-crimson sunset relic summit, selected for the special non-trainer encounter at the Mt Silver summit. Other battles there use the Red summit backdrop.

The two full visual rounds and in-battle results still require player acceptance; passing compilation does not alone prove aesthetic approval.
